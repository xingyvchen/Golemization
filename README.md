# 傀儡化 / Golemization

一个 Minecraft **26.2 Fabric** 模组：用**铜剑**击中生物后，它会**逐渐转化为傀儡方块**。

> **本仓库是源码。** 想直接下载玩，去这里 → [**下载版本（Releases）**](https://github.com/MoYvhan/Golemization_golem-enchant)

---

## 它是怎么运作的

1. 给铜剑附上「傀儡化」附魔
2. 攻击生物 → 触发「铜化」状态效果
3. 生物随时间逐步被铜化，最终变成一尊**铜傀儡雕像**
4. 雕像可以交互、可以摆姿势，不是一块死方块

核心思路是把"击杀"变成"收藏"——**你不是在打怪，你是在收集。**

### 模块划分

```
block / blockentity   铜傀儡雕像方块与方块实体（含雕像姿态数据）
enchantment           傀儡化附魔及其效果
effect                铜化状态效果（渐进转化逻辑）
network               雕像姿态的数据包同步（Payload 模式）
registry              方块 / 方块实体 / 附魔 / 效果 / 粒子 的集中注册
mixin                 对原版生物实体的行为注入
util                  雕像渲染帧缓存、动画补充、玩家工厂
```

### 两个值得说的地方

**① 雕像姿态是数据，不是硬编码。**
`StatueFrameData` / `StatueFrames` / `StatueFrameCache` 构成一条"姿态帧"链路，
配合 `StatueFrameCursorPayload` 等一系列网络包，让客户端与服务端的姿态状态保持一致。
新增姿态只需添加数据，不需要改渲染代码。

**② 渐进转化必须分两段跑。**
转化的"计时"在服务端（`CopperizationEffect`），"表现"在客户端（粒子 + 模型替换）。
中间靠 `ModNetworking` 同步，否则单人游戏看起来正常、联机就会错位。
